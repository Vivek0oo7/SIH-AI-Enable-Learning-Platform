# SkillGov AI Frontend — SIH Prototype

A working frontend prototype for the AI-enabled Skill Intelligence & Learning Platform.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. No server or installation is required.

## Included
- Dashboard
- Official profile
- AI skill-gap analysis
- Personalized course recommendations
- AI quiz generator UI with file selection
- AI learning assistant with demo responses
- Progress analytics
- Settings

## Note
This is a frontend/demo prototype. iGOT/NSSTA APIs, authentication, real LLM calls, document parsing, database storage, and production security still need a backend/integration layer.
